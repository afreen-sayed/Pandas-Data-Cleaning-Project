# Café Shop Data Cleaning Project (Pandas)

### Overview
This project focuses on **data cleaning and preprocessing** using **Python and Pandas**.
The dataset represents transactions from a café shop, including items, quantities, and spending details.
The goal is to clean, structure, and prepare the data for further analysis and visualization.

### Objectives
- Identify and handle **missing values**
- Fix **incorrect data types** (e.g., date columns)
- Create new derived columns like **Price Per Unit** and **Total Spent** 
- Extract **month names and abbreviations** from transaction dates
- Export the cleaned dataset for analysis or SQL import

### Tools & Libraries Used
- **Python 3**
- **Pandas** – for data cleaning and transformation 
- **Jupyter Notebook** – for analysis and documentation

### Key Insights
- Missing prices were successfully filled based on item type  
- All transaction dates standardized for time-series analysis  
- Derived metrics (`Price Per Unit`, `Total Spent`) enable profit and sales analysis  
- Dataset now ready for **visualization using Seaborn or Matplotlib**
